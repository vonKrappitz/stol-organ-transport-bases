# Voivodeship boundaries, file wojewodztwa.geojson

Source: polska-geojson, https://github.com/ppatrzyk/polska-geojson
Variant: wojewodztwa-medium, 16 voivodeships, about 77 thousand outline points.

The file is stored here so that the reproduction runs without network access. The
map scripts read it from this directory and fetch it only if it is absent.
